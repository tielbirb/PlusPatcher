# PlusPatcher
PlusPatcher is an Android app that patches Baldi's Basics mobile APKs with PC mod assets. Pick an APK and a .zip/.rar mod, and it injects the files, re-signs the APK and exports it. Runs in the background, has 5 UI colours and a MIUI/HyperOS tip. Made by tielbirb (2026). Apache 2.0. Not affiliated with the Baldi's Basics Modding Team.
